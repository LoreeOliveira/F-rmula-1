🏎️ PITWALL - GP de São Paulo

Uma landing page moderna e responsiva de um evento de Fórmula 1, focada no Grande Prêmio de São Paulo.

💻 Sobre o projeto

O PITWALL é uma interface web estática criada para simular a página oficial do GP de São Paulo. O layout conta com tema escuro (Dark Mode), exibição do grid de pilotos destacando as cores das equipes, tabela de classificação e um formulário validado para simulação de compra de ingressos.

🚀 Como rodar este projeto

Este projeto não possui dependências complexas. Para visualizá-lo em sua máquina:

Clone o repositório:

git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git


Entre na pasta do projeto:

cd SEU-REPOSITORIO


Abra o arquivo index.html diretamente no seu navegador de preferência.
(Recomendação: Utilize a extensão Live Server no VS Code para visualizar as alterações em tempo real).
